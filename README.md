# Ralph Laurence — Developer Portfolio

The portfolio of **Ralph Laurence C. Sayo**, a full stack developer and fourth-year BS Information Technology student. It presents selected projects, technical skills, certifications, and contact information.

**Live site:** [ralph-portfolio-tau.vercel.app](https://ralph-portfolio-tau.vercel.app/)

## Highlights

- Featured GraphiScan capstone project and technology stack.
- Interactive skill explorer and linked certifications.
- Light and dark themes with a circular view transition.
- Responsive layouts for desktop, tablet, and mobile.
- Animated hero and scroll reveals.

## Built with

Nuxt 4, Vue 3, GSAP, ScrollTrigger, and custom CSS. The site is deployed on Vercel.
